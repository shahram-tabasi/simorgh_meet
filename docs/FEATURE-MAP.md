# نقشه قابلیت‌ها و وضعیت پیاده‌سازی — Simorgh Meet On-Premise 0.2.0

راهنمای وضعیت: **✅ آماده** (در بسته کار می‌کند) · **🟡 بخشی** (هسته آماده؛ پورتال/API تکمیلی لازم است) · **⬜ برنامه‌ریزی‌شده**

| # | قابلیت | وضعیت | آنچه اکنون موجود است | آنچه باقی مانده |
|---|---|---|---|---|
| 1 | کاملاً لوکال | ✅ | بسته آفلاین واحد شامل Docker، Compose، همه ایمیج‌ها و مدل‌ها؛ `--pull never`؛ مدل‌ها با `HF_HUB_OFFLINE` | — |
| 2 | زیرساخت موجود | 🟡 | نصب روی هر لینوکس x86_64 با systemd؛ استفاده از Docker موجود (≥24)؛ گواهی سازمان؛ DNS داخلی؛ Keycloak آماده User Federation (LDAP/AD) | راهنما/پیش‌تنظیم اتصال AD؛ SMTP سازمان |
| 3 | جلسه خصوصی و عمومی | 🟡 | ستون `visibility` (private/internal/public) در `meetings` و `rooms`؛ lobby؛ میزبان احرازشده | اعمال سیاست در API و صدور JWT اتاق‌محور (حالت `jwt`) |
| 4 | دعوت اعضای داخلی و مهمانان خارجی | 🟡 | مهمان با لینک (حالت internal)؛ پشتیبانی NAT/IP عمومی و TURN؛ جدول دعوت‌نامه یک‌بارمصرف هش‌شده | endpointهای دعوت و ارسال ایمیل/پیامک |
| 5 | مدیر جلسه و سطوح دسترسی | 🟡 | میزبان/moderator جیتسی، lobby، کنترل صدا/تصویر (AV moderation)، اتاق‌های جانبی؛ `meeting_participants.permissions` | اعمال نقش‌ها از API در توکن جلسه |
| 6 | اشتراک صفحه و فایل | 🟡 | اشتراک صفحه جیتسی ✅؛ جدول `meeting_files` | API بارگذاری/دانلود فایل با پیوند امضاشده |
| 7 | ضبط و آرشیو جلسات | 🟡 | Jibri (ضبط سرور)، سیاست نگهداری با timer روزانه، جدول `recordings`، پشتیبان‌گیری با `--with-recordings`، رونویسی خودکار ضبط‌ها | صفحه آرشیو و کنترل دسترسی به ضبط‌ها |
| 8 | ثبت حضور و غیاب | 🟡 | جدول‌های `attendance_sessions` و view گزارش `meeting_attendance_report`؛ رویدادهای ورود/خروج در رونوشت Jigasi | دریافت رویدادهای Jitsi در API و تکمیل خودکار جلسات حضور |
| 9 | صورت‌جلسه و پیگیری اقدامات | 🟡 | `meeting_minutes` (نسخه‌دار، پیش‌نویس/تأیید)، `action_items` (مسئول، مهلت، اولویت، وضعیت)، فایل Markdown فارسی، `simorgh-meet minutes list/regenerate` | صفحه بازبینی/تأیید و پیگیری اقدامات |
| 10 | اتصال به تقویم | ⬜ | `ical_uid`/`ical_sequence` در جلسات، جدول توکن فید ICS هش‌شده | endpoint فید ICS و دعوت‌نامه `.ics` |
| 11 | اتاق دائمی واحدها و گروه‌ها | 🟡 | `organization_groups`، اعضای گروه، `rooms` دائمی با سیاست پیش‌فرض ضبط/AI؛ نگاشت خودکار اتاق جیتسی → اتاق دائمی → جلسه (تأیید شده در آزمایش زنده) | مدیریت اتاق‌ها در پورتال |
| 12 | **تولید خودکار صورت‌جلسه با AI** | ✅ | رونویسی زنده فارسی هر سخنران، refine، LLM محلی با خروجی ساخت‌یافته، اقدامات با مسئول و مهلت شمسی، ذخیره در DB و فایل، واژه‌نامه سازمان، ابزار تنظیم مدل کرمانی | سنجش کیفیت مدل‌های واقعی روی صوت سازمان؛ تنظیم مدل کرمانی با داده داخلی |
